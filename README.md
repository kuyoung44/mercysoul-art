# MercySoul Art

AI-powered symbolic talisman generator for MercySoul Dominion.

## Deployment

Deploy this repository to Vercel as a static frontend with a serverless API route.

### Environment variable

Add the following Vercel Environment Variable:

`GEMINI_API_KEY`

Never put the API key in `index.html` or client-side JavaScript.

## Usage

Enter a vision such as **A golden shield for my family** and select **Generate Talisman**.
